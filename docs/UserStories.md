# User Stories

## Authentication

- As a user, I want to create an account so that my incident records remain private.
- As a user, I want to securely log in to access my data.

## Incident Management

- As a user, I want to create a new incident record.
- As a user, I want to edit an incident.
- As a user, I want to delete an incident.

## Evidence

- As a user, I want to upload photos, videos, and documents as evidence.
- As a user, I want to view all evidence related to an incident.

## Timeline

- As a user, I want to see all incidents arranged chronologically.

## Reports

- As a user, I want to generate a PDF report of an incident.
