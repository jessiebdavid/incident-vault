# Incident Vault Design System

## Design Philosophy

Incident Vault is designed to feel safe, trustworthy, and calming.

Users may interact with the platform during stressful situations, so the interface should reduce cognitive load through simplicity, consistency, and accessibility.

---

# Design Style

- Soft Minimalism
- Modern
- Clean
- Inclusive
- Accessible
