# Component Library

## Overview

The Incident Vault Component Library defines reusable UI elements that ensure consistency, accessibility, and maintainability throughout the application.

---

# Buttons

## Primary Button

Purpose:
Main actions

Examples:
- Login
- Register
- Save Incident
- Generate Report

Style:
- Background: Ocean Blue
- Text: White
- Border Radius: 12px

---

## Secondary Button

Purpose:
Alternative actions

Examples:
- Cancel
- Back
- Edit

Style:
- White background
- Blue border

---

## Danger Button

Purpose:
Destructive actions

Examples:
- Delete Incident
- Delete Report

Style:
- Red background
- White text
